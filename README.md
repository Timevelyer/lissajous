# 李萨如图形 · 交互演示

在线演示：<https://timevelyer.github.io/lissajous/>

两个互相垂直的简谐振动，在同一个点上叠加。调整整数频率比与初相位差，曲线会即时重绘。

## 打开方式

- 直接双击 `index.html`（无需联网、无需安装依赖）。
- 或双击 `启动网页.bat`，在本机打开 <http://127.0.0.1:8791/>。

## 可调参数

| 控件 | 范围 | 说明 |
| --- | --- | --- |
| 频率比 n : m | 整数 1 – 8 | X 轴频率 n，Y 轴频率 m；相同频率比会显示约分结果 |
| 初相位差 Δφ | 0° – 360° | 预设 0°、45°、90°、135°、180°、270° |
| 动画速度 | 0.25× – 2× | 每圈基准时长 6 秒 |
| 投影辅助线 | 开 / 关 | 显示点到 x、y 轴的投影 |
| 暂停 | 按钮 | 定格当前相位，便于讲解 |
| 导出 PNG | 按钮 | 导出 1600 × 1760 的印刷版图，含参数标注 |

参数会同步写进网址的 `#n=…&m=…&phi=…&speed=…`，复制链接即可复现同一图形。

## 物理约定

取振幅 A = B = 1，归一化时间 t 从 0 到 1：

```
x(t) = sin(2π · n · t)
y(t) = sin(2π · m · t + Δφ)
```

- n、m 为整数，因此两个分振动在 t = 1 时都完成整数个周期，轨迹闭合。
- n = m 时：Δφ = 0° 或 180° 为直线，90° 或 270° 为圆，其余角度为椭圆。
- n ≠ m 时：相位差改变曲线张开的方向与疏密。

## 文件

- `index.html` — 单文件演示，全部样式与脚本内嵌。
- `server.js` — 可选的本地静态服务器（端口 8791）。
- `启动网页.bat` — 启动服务器并打开浏览器。
